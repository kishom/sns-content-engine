# 音声クレジット（投稿時に必須）

`cat-ckd_reel_voiced.mp4` の音声は **VOICEVOX** で合成している。
VOICEVOX は**商用・非商用問わず無料で利用できる**が、**クレジット表記が義務**。
**クレジットを省略して投稿してはいけない。**

## キャプション末尾に貼る文（コピペ用）

```
音声合成: VOICEVOX:波音リツ / VOICEVOX:春日部つむぎ
```

> ⚠️ `VOICEVOX:<キャラクター名>` が**規定の形式**（半角コロン・スペースなし）。
> 「VOICEVOXを使った」ことが分かる表記が必須なので、`VOICEVOX:` の部分を落とさないこと。
> **使っている全キャラクターを列挙する**（1人だけ書くのは不可）。

### どこに書くか

VOICEVOX 公式Q&A（動画の場合）:
> 動画の概要欄や動画内などに記載してください。

- **IG Reels / TikTok / YouTube Shorts** … キャプション（概要欄）に上記を貼る。**全投稿で必須**。
- TikTok・IG は**キャプションが折りたたまれて途中で切れる**ため、キャプション先頭寄りに置くか、
  動画末尾1〜2秒のエンドカードに焼き込むのが安全（現状の動画には未焼き込み＝**キャプション必須**）。

## 使用している声

| キャラ | 声（VOICEVOX スタイル） | styleId | クレジット文字列 |
|---|---|---|---|
| 🐱 ネコネコ | 波音リツ／ノーマル | 9 | `VOICEVOX:波音リツ` |

選定理由（`docs/character.md` の設定と実測 F0 の両方を満たす組み合わせ）:

- ネコネコ＝「落ち着いた低めトーン・クール」→ 波音リツ（実測 F0 中央値 **252.6Hz**）
- イヌイヌ＝「明るく勢いがある」→ 春日部つむぎ（実測 **346.0Hz**）
- 2キャラのピッチ差 **5.44 半音**＝はっきり聞き分けられる（`verify_voice.mjs` の検査項目）

## 本件（PAWS の SNS 啓発リール）での判断

| 論点 | 判断 |
|---|---|
| 商用/法人利用 | ✅ 可。波音リツ・春日部つむぎとも「企業は事前確認」条項なし |
| オリジナルキャラ（ネコネコ/イヌイヌ）に声を当てる | ✅ 両キャラの規約に禁止条項なし |

### ⚠️ 使ってはいけない声（パイプラインの許可リストから除外すること）

- **ナースロボ＿タイプＴ** — 禁止事項に「**故意に医療知識の誤った流布をする及び誤解を生む行為**」
  「**他のキャラクターとして扱うこと**」があり、**本件では二重に抵触**する。名前が医療っぽいので
  選びたくなるが**絶対に使わない**。
- **企業利用は権利者への事前確認が必要**なキャラ（＝確認を取るまで使用不可）:
  青山龍星 / 後鬼 / もち子さん / No.7 / Voidoll / ぞん子 / ユーレイちゃん / **猫使アル・猫使ビィ**。
  （猫使アル/ビィは「猫」キャラで一見ぴったりだが**事前問い合わせ必須**なので選ばない）

### ⚠️ 公開前に必ずやること（本リポジトリの調査環境では一次ソースに到達できていない）

VOICEVOX 本体の規約・各キャラのクレジット文字列は**公式GitHub（voicevox_resource）の一次テキスト**で
確認済み。ただし**各キャラクター権利者サイトの詳細規約**は、調査環境からドメインが遮断されており
**原文を直接読めていない**（検索結果の要約に依拠）。**初回公開前に以下を人間の目で確認すること。**

- 波音リツ: 権利者（canon）の音源利用規約
- 春日部つむぎ: 権利者サイトの利用規約
- 上記いずれかに法人利用の制限が見つかった場合は、
  `scripts/compose/script.config.mjs` の `SPEAKERS` の `styleId` を差し替えて再合成する
  （差し替え候補で法務上クリアなのは 四国めたん=2 / 冥鳴ひまり=14 / WhiteCUL=23 / 小夜/SAYO=46 /
  玄野武宏=11 / 白上虎太郎=32,12 / ずんだもん=3。**ピッチ差 2 半音以上**になる組を選ぶこと）

## 運用ルール

- **モーフィング機能は使わない**（2キャラの規約が重畳し、厳しい方が適用される）
- **生成音声を AI 学習データ・ボイスチェンジャーに流用しない**（多くのキャラで明示禁止）
- 政治・宗教・誹謗中傷・R18 での利用不可（ほぼ全キャラ共通）
- 声を変えたら**このファイルとキャプションのクレジットを必ず同時に直す**
