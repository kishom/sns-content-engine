## 1. アカウント名の候補（5案）

### 1.0 先に決まっている制約（重要）

**4媒体でハンドルを揃えるなら、上限は X の 15文字。**

| 媒体 | ハンドル文字数 | 使える文字 |
|---|---|---|
| **X** | **1〜15文字** | 半角英数字とアンダースコアのみ ← **これが律速** |
| Instagram | 〜30文字 | 英数字・ピリオド・アンダースコア |
| TikTok | 〜24文字 | 英数字・ピリオド・アンダースコア |
| YouTube ハンドル | 3〜30文字 | 英数字・アンダースコア・ハイフン・ピリオド |

→ **候補ハンドルはすべて15文字以内**で設計した。ピリオドは媒体差・打ち間違いの原因になるので**アンダースコアのみ**に統一している。

> ⚠️ **空き状況は本シートでは確認できない（要確認）。** 4媒体すべてで同時に空いていることを Kisho が実際に確認してから確定すること。
> 併せて**同名・類似名の既存アカウントと商標**も確認する（J-PlatPat / 各媒体の検索）。「もちもち」「ぷにぷに」系はキャラクターグッズで既存商標がある可能性があるため、確定前の確認は必須。

### 1.1 候補一覧

#### 案1（キャラ名型）ネコネコとイヌイヌ

## 2. プロフィール文（bio）

### 2.1 名乗りの線引き（この節が bio 設計の核）

匿名で信頼を出す方法は、**「誰が書いたか」ではなく「何にもとづいて書いたか」を示すこと**に限られる。

| 書ける（推奨） | 書けない（禁止） | 根拠 |
|---|---|---|
| 「学会ガイドライン・査読論文を出典にしています」 | 「獣医師監修」「獣医師が解説」「専門家が運営」 | 獣医師法2条／景表法（→ §6.2） |
| 「出典は各投稿に載せています」 | 「専門家のお墨付き」「確かな情報」 | 保証を装う表現 |
| 「診断はしません」 | 「この症状は〇〇です」 | 診断行為 |
| 「気になる変化はかかりつけの動物病院へ」 | 「病院に行かなくて大丈夫」 | 受診機会の阻害 |
| 「一般的な情報です」 | 特定の病院名・所在地・比較優良表現 | 獣医療法17条（→ §6.3） |

**判断基準を一文で:**
> **「資格」ではなく「出典」で信頼を作る。** 「監修」を名乗りたくなったら、それは匿名をやめるべきタイミングであって、匂わせるべきタイミングではない。

> ⚠️ **既存の配信メモに含まれる `#獣医師監修` タグ（`content/2026-07-02_heatstroke/04-distribution.md`）は、本アカウントでは使用禁止。** 匿名運用の方針決定に伴う変更なので、次に同ファイルを触るときに削除すること。

## 3. プロフィールアイコン／バナーの方針

### 3.1 実アセットを見て分かった最大の課題

`assets/char-ref/` の4枚を実際に確認した結果、**そのままアイコンにすると小サイズで判読できない**。

- キャラ本体：クリーム `#EFE9DF` / タン `#E4C9A0`
- 背景：淡いピンク〜クリームのグラデーション
- → **本体と背景の明度差がほぼ無い。** 大きく見れば愛らしいが、**IG/TikTok のフィード上（実質 64〜100px の円形）ではベージュの塊**になる

対して、旧アセット `assets/icon.png`（1080×1080・平面2Dの案B-4）は**太い茶輪郭 `#4A3B2A` があるため小サイズでも形が読める**。ただしこちらは3D化前のスタイルで、**動画本編（3D）と見た目が食い違う**ため、そのまま使うとアイコンと動画が別ブランドに見える。

**→ 結論：既存4枚のトリミングは「暫定」。本命は専用アイコンショットの追加レンダリング。**

### 3.2 本命（推奨）— char3d に「SNSアイコン専用ショット」を追加する

`scripts/char3d/` は**プログラマティックなレンダラー**で、ショットを追加すれば何度でも同じ絵が出せる（`node render.mjs <shot名>`）。以下の条件でショットを1本足すのが最善。

| 項目 | 指定 |
|---|---|
| 出力サイズ | 1080×1080（正方形） |
| 構図 | ネコ左・イヌ右の**顔寄せ**（`placeDuo()` を維持したまま `duoCam()` を寄せる）。胴体は下半分が切れて良い |
| 背景 | **明度を落とした無地**にする。キャラのクリーム/タンとの明度差を確保するため、`#EAD9C6`〜`#DCC7AE` 程度の一段濃いベージュ、または淡いミント/セージ（`#CFE0D5` 前後）。**PAWSオレンジ・VSJレッド・PRIDESゴールドは不可**（§0） |
| 縁 | 背景を円の外まで塗り切る（円形マスクで角が落ちても破綻しない） |
| 文字 | **入れない**（小サイズで潰れる。文字はバナー側の仕事） |

> ⚠️ **納品4ショット（`hero_duo` / `duo_vertical` / `nekoneko_front` / `inuinu_front`）は「Kisho GO済みの正本・原則上書きしない」と `scripts/char3d/README.md` に明記されている。**
> 必ず**新しいショット名**（例 `icon_duo_square`）で追加し、既存4枚は上書きしないこと。

**受け入れテスト（必須）:** 書き出した画像を **64×64 に縮小して円形マスクをかけ**、①犬と猫の2匹だと分かるか ②ネコの灰ぶち・イヌのこげ茶垂れ耳（＝個体識別子）が残っているか、を目視で確認する。ここで落ちたらデュオを諦めて §3.4 のネコ単体に切り替える。

### 3.3 暫定（今すぐ開設する場合）— 既存ファイルからのトリミング指示

いずれも**元画像のピクセル座標**。数値は実レンダリング画像を目視で採寸した**起点値**なので、書き出し後に必ず円形プレビューで確認して微調整すること。

| 枠 | 曜日 | 内容 |

本数を4本に抑える根拠は制作実態にある。Lane B は 1本あたり7カット・約1,200フレームで**レンダリングだけで実測30分**（`scripts/char3d/README.md`）、これに台本・エビデンス収集・音声・合成・コンプラレビューが乗る。毎日投稿は**レビューを飛ばす圧力**になるので選ばない。

## 5. 世界展開の設計

### 5.1 結論

**フェーズ1（開設〜実績が出るまで）：日本語1アカウントに集中。多言語化しない。**
**フェーズ2（日本語で型が固まってから）：英語は別アカウントに分ける。**

### 5.2 理由

**なぜ1アカウント多言語字幕にしないか**
- IG / TikTok は視聴者の言語・反応をもとに配信先を決める。**日本語と英語の投稿が混在すると、どちらの層に配信すべきか判断が定まらず、両方の到達が落ちる**
- コメント欄が2言語で混ざると、返信運用が破綻する（匿名運用では返信の一言が身バレ経路になるため、返信は慎重に統一したい → §6.4）
- 固定投稿・bio・ハッシュタグが**どちらか一方の言語にしか最適化できない**

**なぜ最初から2アカウント同時に立てないか**
- 2言語 × 4媒体＝**8面**。個人運用では回らず、更新が止まったアカウントはブランド毀損になる
- 日本語で「どのフックが効くか」が固まる前に翻訳しても、翻訳する価値のある型がまだない

**なぜ英語版が現実的に作れるか（重要）**
このプロジェクトのテロップは手作業の編集ではなく、**`scripts/compose/` による生成工程**（`@fontsource/noto-sans-jp` を使った合成）。つまり**英語版はテキストを差し替えて再合成すれば出る＝作り直しではなく再実行**。音声は VOICEVOX（日本語）なので英語版は差し替えが必要だが、映像そのもの（3Dレンダリング済みカット）は**そのまま再利用できる**。これがフェーズ2を現実的にしている。

### 5.3 実務上いまやっておくこと

**英語版ハンドルを先に押さえておく。** 運用開始は後でよいが、同名を他人に取られると統一が崩れる。

| | 日本語版 | 英語版 |
|---|---|---|
| ハンドル | `mochi_animals` | `mochi_animal_en`（15文字）※ `mochi_animals_en` は16文字で **X が不可** |
| 表示名 | もちもちアニマルズ | Mochi Animals |

> ⚠️ ハンドルの文字数は X の15文字制限で決まる。**英語版ハンドルまで含めて15文字に収まるか**を、名前を確定する前に必ず検算すること（案1 `nekoneko_inuinu` は既に15文字なので `_en` を足せない＝英語版は別名になる）。

### 5.4 フェーズ2で追加検討が必要なこと

- **エビデンスの出典は共通で良い**（PMC / ACVIM / Merck / WSAVA はいずれも国際的）
- **受診導線の文言は国ごとに違う。** 例えば米国では中毒時の相談先（ASPCA Animal Poison Control 等）の慣行が日本と異なる。「かかりつけの動物病院へ」をそのまま英訳するだけでは不十分
- **規制も国ごとに違う。** 日本の獣医療法・景表法の枠組みは他国には適用されない一方、各国に別の広告・医療情報規制がある。展開先を決めた時点で個別に確認する

## 6. 匿名運用のリスクと注意 ⚠️（最重要）

### 6.1 将来 PAWS と紐づける可能性がある場合 — ステマ規制の論点

**2023年10月1日から、景品表示法の指定告示により「一般消費者が事業者の表示であることを判別することが困難である表示」が不当表示として規制されている**（いわゆるステマ規制）。

**論点が立つのは、次の3つが揃ったとき。**

| # | 要件 | このケースでの当てはまり |
|---|---|---|
| 1 | **事業者が自己の供給する商品・役務の取引について行う表示** | このアカウントが PAWS のサービス・店舗・物販・アプリ等を紹介した時点で該当しうる |
| 2 | **事業者が表示内容の決定に関与している** | **ここが最大の注意点。** 消費者庁の運用基準では、事業者と一体と認められる**従業員・役員による自社商品の SNS 投稿も「事業者の表示」に該当しうる**とされている。Kisho が PAWS 側の立場にある以上、本人が個人として投稿していても「PAWS の表示」と評価される可能性がある |
| 3 | **一般消費者がそれを事業者の表示だと判別することが困難** | **匿名アカウントはこの要件をほぼ自動的に満たす。** 匿名であること自体が、判別困難性を高める方向に働く |

**つまり「匿名で信頼を集めてから自院へ誘導する」という動きは、3要件が最も揃いやすい形。**

**実務上の推奨（優先順）**

1. **【推奨】このアカウントからは PAWS に一切触れない。** 触れた瞬間に匿名運用の意味が失われるうえ、上記の論点が立つ。**「触れない」が最も安全でコストも低い**
2. どうしても紐づけるなら、**紐づける時点で「関係性の明示」を入れる。** 「PR」「広告」あるいは「運営者は〇〇の関係者です」といった表示を、**投稿ごとに、一般消費者が認識できる形で**行う。bio に小さく書いてあるだけでは足りないと評価されうる
3. **後出しの明示は信頼を壊す。** 何万人もフォロワーを集めた後に「実は関係者でした」と明かすのは、法的評価とは別に、コミュニティからの信頼を失う経路として現実的なリスク

**⚠️ 見落としやすい点：措置命令の名宛人は「事業者」であって、投稿した個人ではない。** つまり問題が起きたとき、行政処分のリスクは **PAWS（会社）側に飛ぶ**。「個人の匿名アカウントだから会社は無関係」という整理は成り立たない。

**⚠️ 本節は公開情報にもとづく論点整理であり、法律助言ではない。PAWS との接続を実際に検討する段階になったら、景品表示法に詳しい弁護士等の確認を必ず取ること。**

### 6.2 資格を明示しないことの意味と、その範囲

**獣医師法第2条は「獣医師でない者は、獣医師又はこれに紛らわしい名称を用いてはならない」と定めている。**

したがって、

- **獣医師資格を持たない場合：** 「獣医師監修」「獣医師が解説」「〇〇獣医師」等は**そもそも使えない**。加えて、資格の裏付けがない優良性の表示は景表法上の優良誤認の論点にもなる
- **獣医師資格を持つ場合でも、匿名運用では実質的に使えない：** 匿名では第三者が資格を検証できないため、「獣医師監修」という表示は**実態を確認できない優良性の主張**になる。信頼を担保するはずの表示が、逆に検証不能な主張になってしまう
- **「〜先生」「Dr.」「vet」等をハンドルや表示名に入れるのも同じ理由で不可**（§1.3）

**匿名で許される範囲＝「専門家の保証」を装わない範囲。**

| 立ち位置 | 説明 |
|---|---|
| ✅ このアカウントの立ち位置 | 「一次情報を調べて、分かりやすく紹介する人」。信頼の源は**出典の質と透明性** |
| ❌ 取ってはいけない立ち位置 | 「専門家が保証する情報源」。資格・所属・実務経験を根拠にした権威づけ |

**`docs/character.md` の既存の原則がそのまま答えになっている：**
> ネコネコ＆イヌイヌは獣医ではなく「気づきのきっかけ」を届ける存在。最終判断はかかりつけの獣医師へ。

**アクション：既存の `#獣医師監修` タグを配信テンプレートから削除する**（`content/2026-07-02_heatstroke/04-distribution.md`）。

### 6.3 獣医療法の広告規制（匿名でも対象）

**獣医療法第17条は「何人も」を主語にしている**＝匿名アカウントであっても、飼育動物診療施設の業務に関する広告をすれば対象になりうる。令和6年4月1日施行の改正で広告可能な事項は拡大したが、**誇大広告および他施設と比較して優良である旨の広告の禁止は維持されている。**

**このアカウントでのルール（既存の台本メモと同じ）**
- 特定の病院名・所在地・診療内容を出さない
- 「〇〇病院は優れている」等の比較優良表現を書かない
- **プロフィールやキャプションに、特定の動物病院への誘導リンクを置かない**

> `content/2026-07-22_cat-ckd/02-script.md` の配信メモに既に同趣旨の記載がある。**この方針は匿名運用でも変わらず維持する。**

### 6.4 身バレの経路と対策

**匿名運用が壊れるのは、たいてい一発の決定的な情報ではなく、小さな手がかりの積み重ね。** 経路を潰し切ること。

| # | 経路 | 具体例 | 対策 |
|---|---|---|---|
| 1 | **画像・素材の再利用** | 同じキャラ画像（`char-ref/` `expressions/` `cut-*.png`）が PAWS 側の媒体（paws-buddies のアプリ内、店舗掲示、VSJ の資料）にも出ている → **画像一致で一発で紐づく** | **このキャラを PAWS 側の媒体で一切使わない。** char3d は再現可能なので、SNS 専用のショット体系（別ショット名・別背景色）を作り、PAWS 側とはアセットを完全に分離する |
| 2 | **ファイルのメタデータ** | 書き出し画像・動画の EXIF / 作成者名 / 使用ソフト / GPS | 投稿前にメタデータを除去する工程をパイプラインに入れる |
| 3 | **投稿時間** | 診療時間外にだけ投稿 → 勤務パターンが推測される。深夜の手動投稿が続く | **必ず予約投稿**。操作時刻と投稿時刻を切り離す（§4.2） |
| 4 | **地域の特定** | 背景の実写、方言、季節・天候ネタ（「今日はこっち大雪」）、地域イベント・災害への言及 | 実写背景を使わない。天候・地域ネタは全国一般の表現に留める |
| 5 | **既存アカウントとの連結** | 既存の実名アカウントからフォロー／いいね／リポスト。同一電話番号・メールアドレス。連絡先同期による「知り合いかも」への露出 | **専用メールアドレスを新規作成**。**連絡先の同期を OFF**、**「アカウントを他の人にすすめる」を OFF**。既存アカウントから絶対にフォロー・反応しない。可能なら端末／ブラウザプロファイルも分ける |
| 6 | **文体・言い回しの一致** | 既存の実名アカウントや note と同じ口癖・絵文字の使い方・改行の癖 | **キャラの一人称で書く運用に統一**（＝素の文体を出さない）。これは対策と同時にブランドの一貫性にもなる |
| 7 | **コメント返信での油断** | 「うちの病院では」「私が診た子は」「当院の症例で」→ **一言で獣医療関係者と判明する** | 返信もキャラの声で。**個別の相談には答えず定型文で返す**（下記） |
| 8 | **収益化・支払い情報** | 収益化やプロアカウント設定で本名・銀行口座をプラットフォームへ提出。振込名義が外部に見える経路 | 収益化を有効にする前に、**支払い情報がどこまで公開されるか**を各媒体の規約で確認してから判断する |
| 9 | **フォロワー構成** | 開設直後に業界関係者だけがフォローしている状態 | 初期に知人へ拡散を依頼しない |

**コメント返信の定型文（個別相談への回答を避けるため／必ず用意しておく）**
```
コメントありがとう🐱 心配だよね。
ただ、この子の状態は実際に診てみないと分からないから、
ここで判断はできないんだ。
気になる変化があるなら、かかりつけの動物病院で相談してみてね🏥
```
**この定型文を外れて個別の症状に踏み込んだ瞬間、①診断行為に近づく ②専門知識が露出して身元が推測される、という二重のリスクが立つ。**

### 6.5 医療的断定の禁止・受診誘導 — 匿名でも一切変わらない

**「匿名だから責任が軽い」は成立しない。**

- **民事上の責任は匿名でも残る**（発信者情報開示の手続きが存在する）
- **プラットフォームの医療情報ポリシー違反は、アカウント削除に直結する**。匿名アカウントは失うものが大きい（アカウントが消えれば資産はゼロになり、同じ名前で再建もできない）
- **信頼を失う速度は匿名のほうが速い。** 資格という後ろ盾がない以上、**一度の誤情報で信頼の根拠がすべて消える**

**したがって、以下は開設初日から一切例外なく運用する。**

| ルール | 実装 |
|---|---|
| 全投稿を `vet-marketing-compliance` に通す | `CLAUDE.md` の既存ルール。台本・キャプション・サムネ文言・**bio・固定投稿も対象** |
| 断定表現の回避 | 「〜のことがある」「〜と言われている」。原因を1つに断定しない |
| 出典の明示 | 概要欄／キャプションに一次情報のリンク |
| 画面内免責 | 動画末尾に小さく重ねる：`※一般的な情報です。診断はかかりつけの獣医師へ` — **省略不可** |
| キャプション免責 | 画面内とは別に、キャプション末尾にも記載（**二重化**） |
| 受診導線で締める | すべての健康テーマの出口は「かかりつけの動物病院へ」 |
| 不安を煽らない | 「怖い病気」ではなく「早く気づけばできることが増える」（既存台本の方針を踏襲） |

### 6.6 その他、開設前に整理しておくべきこと

**キャラクターの権利関係。** ネコネコ／イヌイヌの造形・3Dレンダラー（`scripts/char3d/`）が、PAWS / VSJ の業務として制作されたものか、Kisho 個人の制作物かによって、権利の帰属が変わりうる（職務著作の論点）。**個人の匿名アカウントの看板として使う前に、この帰属を明確にしておくこと。** 後から「会社の資産だった」となると、アカウントごと立ち行かなくなる。
